# INFINITY EARN 5.0 – START HIER

## Was ist enthalten?

Dieses Paket ist eine **vollständige technische Übergabe an Claude Code**, keine bereits einsatzbereite Geldmaschine.

- `CLAUDE_CODE_MASTERPROMPT.md` – vollständiger KI-Produktionsauftrag
- `ARCHITEKTUR_UND_BETRIEB.md` – Start-, Sicherheits- und Betriebsdesign
- `KOSTEN_UND_RECHT.md` – 0-€-Fixkosten-Regel, Claude-Limits, Steuer-/Akquise-Hinweise
- `TESTS_100.md` – 100 positive und negative Abnahmetests
- `schemas/*.json` – minimale Beispielverträge für Angebote, Orders, Leads, Invoices
- `.env.example` – ausschließlich Beispielvariablen, keine echten Zugangsdaten

## So übergibst du es Claude Code

1. ZIP-Datei auf deinem PC entpacken.
2. Einen **neuen unabhängigen Projektordner** `infinity-earn` öffnen; keine Trendo- oder Vecom-Projekte verwenden.
3. Claude Code starten und die Datei `CLAUDE_CODE_MASTERPROMPT.md` als Auftrag nennen. Wenn Claude Code Zugriff auf den Ordner hat, kann es die anderen Dateien selbst lesen.
4. Claude Code anweisen: „Führe zunächst M0 aus. Erzeuge echte Tests und lauffähigen Code. Markiere Demos und echte Daten strikt getrennt. Keine bezahlten Dienste einschalten.“
5. M0/M1-M2 im Testmodus prüfen, bevor Liveverkauf überhaupt möglich ist.

## Sofort nutzbare Nachricht zum Kopieren

> Lies zuerst `CLAUDE_CODE_MASTERPROMPT.md`, dann alle Dateien dieses Pakets. Implementiere INFINITY EARN als eigenständiges Projekt, beginne mit Meilenstein M0. Baue echten Code, Tests und Deployment-Dokumentation, keine reine Produktpräsentation. Aktiviere keine externen Kosten, keine echte Akquise und keine echten Zahlungen ohne die beschriebenen rechtlichen Freigaben. Gib am Ende nur nachprüfbare Fortschritte und offene Blocker aus.

**Wichtig:** Der spätere Übergang zu LIVE erfordert eine echte rechtlich und steuerlich geprüfte Unternehmens- und Zahlungsanbieter-Konfiguration durch den Eigentümer. Claude ist kein legaler Geschäftsführer und ein Abo ist keine unbegrenzte kostenlose KI-API.
